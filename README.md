# P2A Formation — plateforme web

Ce dépôt accueille la future plateforme P2A Formation : une expérience unifiée de découverte, de conseil et de conversion pour les particuliers comme les entreprises.

## Méthode de travail

Chaque évolution doit être vérifiable :

1. une étape de conception Figma avec lecture et capture ;
2. une évolution de code isolée ;
3. un commit GitHub via le connecteur ;
4. une preuve de relecture du dépôt.

## État du projet

- Statut : cadrage produit et design system.
- Source de vérité : ce dépôt GitHub et le fichier Figma partagé.
- Développement des pages : après validation du document de conception.

## Principes produit

- inspirer confiance en moins de dix secondes ;
- simplifier le choix d’une formation ou d’un accompagnement ;
- guider naturellement vers une prise de contact ;
- privilégier une architecture durable, accessible et maintenable.
